# MedicalMonitorProject 医疗监控系统

这是一个基于 Python 后端与 Vue 前端开发的医疗数据/人体姿态监控系统。

## 🛠️ 技术栈

* **后端**：Python, Flask / FastAPI, OpenCV
* **前端**：Vue.js, Vite
* **依赖管理**：pip, npm
